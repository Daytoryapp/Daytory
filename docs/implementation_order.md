# 단계별 구현 일정 (실행 기준)

## Phase 1. 데이터 계층
- `DateLog` 모델 정의
- 메모리 기반 `DateLogRepository` CRUD 작성
- Riverpod `DateLogController` 연결
- 완료 조건: 추가/삭제 시 리스트 즉시 반영

## Phase 2. 기록 작성/상세
- `AddLogScreen` 폼 및 유효성 검증
- `DetailScreen` 상세 정보 표시
- 완료 조건: 저장 후 데이터가 다른 탭에서도 동일하게 보임

## Phase 3. 캘린더 탭
- `TableCalendar` 이벤트 로더 연결
- 날짜 선택 시 해당 날짜 기록 리스트 노출
- 완료 조건: 기록 있는 날짜 점 표시, 날짜 변경 시 리스트 갱신

## Phase 4. 지도 탭
- `FlutterMap` + OSM 타일 연동
- 마커 탭 바텀시트 미리보기 및 상세 이동
- 완료 조건: 모든 기록 좌표가 마커로 렌더링

## Phase 5. 필터/통계
- 태그/감정 필터 상태 추가 및 적용
- 통계 카드(총 횟수/총 비용/평균 감정/월별 횟수) 구현
- 완료 조건: 필터 적용 즉시 캘린더 리스트 결과 변화

## 다음 릴리즈 후보
- Drift/Hive 영속 저장
- 이미지 첨부
