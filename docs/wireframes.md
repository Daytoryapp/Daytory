# 와이어프레임 (텍스트 버전)

## 1) 홈 탭 구조

`[캘린더] [지도] [기록 추가] [통계]`

## 2) 캘린더 화면

```text
+--------------------------------------------------+
| 캘린더                                  [필터]    |
+--------------------------------------------------+
|                 2026년 4월                       |
|   일   월   화   수   목   금   토               |
|            ... 날짜 셀 + 기록 점 표시 ...         |
+--------------------------------------------------+
| 2026.04.25                             총 2건     |
+--------------------------------------------------+
| [카드] 주말 브런치 데이트                         |
|      망원 한강공원 · 감정 5점 · 48000원           |
+--------------------------------------------------+
| [카드] 저녁 영화 데이트                           |
+--------------------------------------------------+
```

## 3) 지도 화면

```text
+--------------------------------------------------+
| 지도                                [검색][필터]  |
+--------------------------------------------------+
|                                                  |
|                   지도 + 마커                    |
|                                                  |
|            (마커 탭 시 하단 미리보기)            |
|                                                  |
+--------------------------------------------------+
| 마커를 탭하면 해당 데이트 기록 미리보기           |
+--------------------------------------------------+
```

## 4) 기록 작성 화면

```text
+--------------------------------------------------+
| 기록 작성                                         |
+--------------------------------------------------+
| 제목(선택)                                        |
| 장소                                              |
| 위도                | 경도                       |
| 메모 (멀티라인)                                  |
| 비용                                              |
| 태그(쉼표구분)                                    |
| 감정 점수 Slider (1~5)                            |
|                                      [저장]       |
+--------------------------------------------------+
```

## 5) 상세 화면

```text
+--------------------------------------------------+
| 데이트 상세                                       |
+--------------------------------------------------+
| 제목/장소                                         |
| 날짜/시간                                         |
| 장소, 비용, 감정, 메모                            |
| 태그 Chip 목록                                    |
| 지도 미니뷰(좌표)                                 |
+--------------------------------------------------+
```
