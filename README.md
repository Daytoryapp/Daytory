# Flutter 데이트 기록 앱

캘린더(시간 축)와 지도(장소 축)를 동등한 홈 탭으로 제공하는 데이트 로그 앱입니다.

## MVP 범위

- 기록 CRUD: 제목, 장소, 좌표, 메모, 태그, 비용, 감정 점수 저장/수정/삭제
- 캘린더 탐색: 기록 날짜 인디케이터 + 선택 날짜 리스트
- 지도 탐색: 마커 표시 + 바텀시트 미리보기 + 상세 이동
- 필터: 태그/감정 기준 필터
- 통계: 총 횟수, 총 비용, 평균 감정, 월별 횟수

## 기술 스택

- 상태관리: `flutter_riverpod`
- 캘린더 UI: `table_calendar`
- 지도 UI: `flutter_map` + `latlong2` (OpenStreetMap 타일 사용)
- 포맷팅/기타: `intl`, `uuid`

## 폴더 구조

- `lib/src/models`: 도메인 모델
- `lib/src/data`: 리포지토리
- `lib/src/state`: 전역 상태 및 필터 상태
- `lib/src/features`: 화면 단위 기능(`calendar`, `map`, `add`, `detail`, `stats`)
